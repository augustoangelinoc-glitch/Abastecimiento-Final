# Abastecimiento Final

Aplicación Streamlit para analizar consumo, stock, Lead Time y cantidad a abastecer.

La descripción oficial proviene exclusivamente de la columna B (`Descripción`) de Stock Actual.

## Archivos de entrada
- Stock actual
- Salidas
- Órdenes de compra
- Ingresos de OC

## Lead Time
Cruce por P. Emis + Número + Material contra P.OC + Número OC + Material. Se usa la primera recepción.
